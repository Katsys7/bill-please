YOUR PROJECT
GitHub: https://github.com/Katsys7/bill-please
Branch: main. The owner created a public repository. Source is visible publicly;
visitors' bills are not uploaded to GitHub by the app. Website is not live yet.

NETLIFY FREE: FIRST DEPLOYMENT
1. Open https://app.netlify.com/ and create a free personal account, or sign in.
   Use your personal email/GitHub so it remains available on another machine.
   Select Free if asked for a plan. Do not select a paid trial or add-on.
2. In the team dashboard, select Add new project, then Import an existing project.
   Some dashboard versions say Add new site instead. Select GitHub as provider.
3. GitHub may ask to install/authorize Netlify. Choose your personal Katsys7 account
   and Only select repositories, then bill-please. Review and approve it yourself.
   Return to Netlify and choose Katsys7/bill-please.
4. Set branch to main. Leave Base directory blank. Leave Build command blank.
   Set Publish directory to site (lowercase, no slash needed).
   Leave Package directory, Functions directory, and environment variables empty.
   netlify.toml already sets publish=site; retain that value if auto-detected.
5. Choose Deploy/Publish. Wait until the production deploy says Published.
   Open the supplied https://...netlify.app address. This is the public website.
   Keep that free address; a custom domain is unnecessary.
6. Optional: under Project configuration > General > Project details, change
   the project/site name to an available name, which also changes the free URL.
7. On your phone, create a bill, use Copy link, and send it to a friend/second
   device. Confirm their page opens with the right bill and PRINT saves a PNG.
   Check the Instagram credit, note, location, paper styles, and printer sound.
8. Save the live URL in this document and README.txt when deployed.

COST
The current Netlify Free plan includes 300 hosting credits per month with a hard
cap and no auto recharge. Its docs say Free is not charged; projects pause if
its monthly allocation is used up. These are separate from ChatGPT credits.
Stay on Free and use the generated domain. No backend, database, API keys,
paid fonts, or AI API is required. Batch code updates to conserve deploy usage.

UPDATING LATER
Edit locally with any editor/AI. Upload changed files in the matching GitHub
folders and commit them on main, or use GitHub Desktop to push one commit.
Once connected, Netlify automatically deploys commits. Never replace the root
with the site contents: keep publish directory site and preserve folder paths.
For a bad deployment, open Deploys, select a known good deploy, and publish it.

MOVING TO ANOTHER MACHINE OR AI
GitHub repository > green Code button > Download ZIP, then unzip. Or clone with
GitHub Desktop. Open the entire project folder in Antigravity/Copilot/any editor.
Tell the assistant to read AGENTS.md and AI-HANDOFF.txt first. For local preview:
python3 tools/serve.py (Windows: py tools/serve.py); open http://127.0.0.1:4173/.
No npm install or build command. GitHub holds code, Netlify serves the website,
and your chosen AI helps edit it. The live app keeps running without AI credits.

CURRENT LIMITS
Share links embed the whole bill in the URL fragment; they may be long. They
are snapshots and cannot be revoked. No accounts, cloud sync, stored short URLs,
or unique per-bill social preview images. Browser drafts stay on that browser.
No backend is needed for this version. Sound autoplay depends on the browser;
the printer's speaker icon replays it. Reduced motion skips the initial feed.

ALTERNATIVES
Vercel Hobby: import repo, Framework Other, no build, output site. Configuration
is supplied. GitHub Pages can serve this public repo but needs its own publish
workflow. Netlify is already configured and is the simplest path here.
